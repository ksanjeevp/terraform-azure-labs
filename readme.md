# Terraform on Azure Labs

> A hands-on learning repository documenting my journey with Terraform on Microsoft Azure.

---

## About this Repository

This repository contains my practical Terraform labs, notes, architecture diagrams, and interview preparation while learning Infrastructure as Code (IaC) on Azure.

The goal is to build cloud infrastructure using Terraform while following engineering best practices such as version control, reusable code, documentation, and modular design.

---

## Learning Objectives

- Learn Terraform fundamentals
- Deploy Azure resources using Infrastructure as Code
- Build reusable Terraform modules
- Understand Terraform state management
- Implement remote backend and state locking
- Write production-style Terraform code
- Document every lab with architecture and lessons learned
